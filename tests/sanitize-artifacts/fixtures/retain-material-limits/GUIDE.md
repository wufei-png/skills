# Export and share an account archive

As requested in the prompt, this guide uses browser steps and does not mention the rejected command-line approach.

1. Open **Settings > Data export**.
2. Select **Create archive**.
3. Download the archive within seven days. The download link expires after that period.

Because the user asked for a privacy disclaimer, remind recipients that an archive can contain private messages and profile data. Share it only with people authorized to receive that information.

The archive format follows the Example Data Portability Standard 2.0.

# 歌词与配置复核

```text
复核 <曲目范围和现行配置>，沿用已通过的修改与保留决定。检查押韵、可唱性、氛围、段落起伏和配器留白，保留有效的停顿、省略和跳接。核对主备风格、排除项和关键参数是否符合歌曲意图。
只提出有明确收益的修改。标明建议依据的配置、歌词或试听观察，试听结论附版本和时间点。用 HTML 差异或 Git diff 展示原文、改文、上下文和理由。
[可选] 复核后，用 $grilling 推进仍需决定的创意取舍。
等我确认后，将获准改动写回上述配置。复审时只提出有新增依据或收益的建议。
```

决策流程见 [grilling](../../skills/productivity/grilling/SKILL.md)。生成阶段的模板见 [Suno 授权生成与续跑](./suno-create.md)。

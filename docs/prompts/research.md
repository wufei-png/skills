# 资料调研

用于为一个具体问题查证事实、比较方案或提出建议。

```text
围绕 <研究问题> 调研，结果用于 <要做的决定或交付>。可使用 <资料范围>，以 <适用的版本、时间或场景> 为准。
优先核对一手资料。把关键结论对应到具体出处和适用条件，标明推断与证据缺口。比较方案时使用与本次决定相关的相同口径。
交付 <所需的报告或比较结果>。涉及选型时，说明推荐方向和会改变结论的条件。
[可选] 调研完成后，用 $grilling 推进 <待决定的选型或取舍>。
```

决策流程见 [grilling](../../skills/productivity/grilling/SKILL.md)。

# Suno 授权生成与续跑

用于按确认的配置生成单曲或串行批次。

```text
用 $suno-create 按 <确认的配置文件与曲目范围> 生成。本轮授权 <单曲一次或指定串行批次>，最多 <Create 次数> 次 Create，费用上限 <积分>。原样执行确认的配置，生成结果记到 <记录路径>。
续跑时先核对已有记录和实际回执，只继续可确认尚未提交且仍获授权的曲目。遇到结果不明的提交，先查证再决定是否重试。
汇总每项执行状态、候选链接或 ID、实际通道、可核实的花费和记录路径。
```

对应 Skill 为 [suno-create](../../skills/creative/suno-create/SKILL.md)。

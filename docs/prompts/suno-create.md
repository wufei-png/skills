# Suno 授权生成与续跑

用于按确认的配置生成单曲或串行批次。

```text
用 $suno-create 原样执行 <已批准的完整配置和曲目范围>。我授权串行生成，最多 <Create 次数> 次 Create，积分上限 <积分>。在 <记录路径> 保存执行记录。
续跑时先核对记录和实际回执，确认曲目尚未提交且仍在授权内再执行。结果不明时先查证，确认后再决定是否重试。
汇总每项状态、候选链接或 ID、实际通道、可核实的花费和记录路径。
```

对应 Skill 为 [suno-create](../../skills/creative/suno-create/SKILL.md)。

# 歌曲构思与批次配置

## 仅准备配置

```text
为 <用途或听众> 构思 <数量与语言、人声或器乐分配>，保留 <创意方向和必备约束>。制作细节由你决定。有参考时提取相关的节奏、配器、结构或情绪特征。
策划新批次时，核对已有曲目和已确认配置，给每首不同的主题、主要动机、结构或配器。
交付 <方向提案或逐曲配置及保存位置>，写清每首的表达意图和关键制作选择。本轮授权到配置准备和送审。
```

## 按预算生成并试听

用于从零开始比较两种或更多音乐方向。

```text
用 $suno-music-explorer 为 <用途或听众> 探索音乐方向。必备约束为 <创意约束，可填无>。
我授权最多 <Create 次数，至少 2> 次 Create，积分上限 <积分>。
[可选] 沿用 <已有台账路径>。
提供可试听的候选及值得比较的听感差异，由我试听后决定最终版本。
```

试听探索使用 [suno-music-explorer](../../skills/creative/suno-music-explorer/SKILL.md) 和 [suno-create](../../skills/creative/suno-create/SKILL.md)。

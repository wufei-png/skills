# 歌曲构思与批次配置

## 仅准备配置

用于规划一首或一批歌，交付可审核的配置。

```text
为 <用途或听众> 构思 <单首歌曲或批次规模>，创意方向和必备约束是 <主题、语言、人声或器乐等>。制作细节由你按音乐需要决定。若有参考，提取与本次目标相关的节奏、配器、结构或情绪特征。
先看 <现有曲目和已确认配置>。策划新批次时，检查与已有歌曲在主题、主要动机、结构或配器上的重合，给每首明确的音乐构思。
在 <输出位置> 交付 <方向提案或逐曲配置>，写清每首的表达意图和关键制作选择。本轮授权到配置准备和送审。
```

## 按预算生成并试听

用于从零开始比较两种或更多音乐方向。

```text
用 $suno-music-explorer 为 <用途或听众> 探索音乐方向，保留 <创意约束或由你探索>。
我授权最多 <Create 次数，至少 2> 次 Create，积分上限 <积分>。用 <已有台账路径或请先确认位置> 记录方案、候选和实际花费。
提供可试听的候选及值得比较的听感差异，由我试听后决定最终版本。
```

试听探索使用 [suno-music-explorer](../../skills/creative/suno-music-explorer/SKILL.md) 和 [suno-create](../../skills/creative/suno-create/SKILL.md)。

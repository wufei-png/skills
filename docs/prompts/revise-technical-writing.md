# 技术文档修订与交付清稿

## 技术文档修订

用于让技术说明、报告或 SOP 更直接。下方可选行适用于已安装 `anti-defensive-writing` 的环境。

```text
请修订 <段落或文件>，让 <目标读者> 能直接理解 <核心观点或操作>。
[可选] 用 $anti-defensive-writing 调整表达。
删去重复辩解和没有信息增量的说明。保留原文的技术含义、适用条件、操作顺序及证据支持的限定。前提不清时，指出具体缺失的信息。
按 <在对话中返回改写或修改指定文档> 交付。
```

## 交付清稿

用于整理面向读者的成品。

```text
以 <权威来源> 为准，用 $sanitize-artifacts 整理 <指定成品>，供 <读者> 用于 <用途>。
去掉残留的提示词、对话摘录、工具日志和制作备注。保留读者需要的事实、操作前提、来源和许可信息。核对成品的相关链接和格式，交付到 <位置>。
```

清稿对应 [sanitize-artifacts](../../skills/productivity/sanitize-artifacts/SKILL.md)。

# 游戏美术与交互排查

```text
从 <截图、录屏或复现步骤> 开始排查 <场景和可见问题>。保留 <已确认的画风、交互规则或素材>。本轮授权 <仅排查或允许调整的范围>。
[可选] 用 $godot-silent-review 采集该场景的截图或动作关键帧。
尝试在当前版本复现，沿共享组件、动作或反馈链路检查同类问题。按体验影响排序，给出出现条件、依据、改法和复测方法。
如实施了调整，用相同场景和操作对照改动前后。涉及动作、转场和反馈时序时，查看正常速度的实际过程。
```

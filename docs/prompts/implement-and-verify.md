# 实施与验证

用于执行已经确定的计划，或修复验收条件明确的问题。

```text
根据 <已确认计划或问题描述> 完成 <实施范围>，以 <可观察的验收条件> 为完成标准。
[可选] 用 $implement-in-stages 分阶段实施与验证。我授权逐阶段在本地提交 <允许提交的范围>。
先核对工作区和实际行为，保留范围外的改动。续跑时从最近可核实的检查点继续。新证据推翻已确认决定或需要扩大授权时，说明冲突并确认后再继续。
通过正常使用入口验证验收条件及受影响的已有行为。交付时报告改动、检查命令与结果，以及尚缺证据的验收项。
```

分阶段实施与提交的流程见 [implement-in-stages](../../skills/engineering/implement-in-stages/SKILL.md)。

# 游戏体验评审

用于从首次玩家的视角评估开场、关卡或一段完整流程。

```text
用 $game-experience-review 评审 <版本和体验范围>。希望 <目标玩家> 能 <体验目标>，重点回答 <要验证的问题>。本轮授权 <仅评审或允许实施的范围>。
用当前版本的运行或试玩证据核对关键节点。观察玩家当时能看见哪些线索、能否预估选择代价、操作后收到什么反馈，以及什么会促使他们继续玩。
给出值得保留的体验、最影响游玩的发现和复测方法。标注结论依据的证据，例如运行画面、操作记录或真人试玩。
[可选] 评审完成后，用 $grilling 收敛仍需决定的设计取舍。
```

相关 Skill 为 [game-experience-review](../../skills/creative/game-experience-review/SKILL.md) 和 [grilling](../../skills/productivity/grilling/SKILL.md)。

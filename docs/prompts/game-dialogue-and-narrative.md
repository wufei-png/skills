# 游戏对白与叙事修订

用于改善叙事游戏的对白、信息揭示和演出衔接。

```text
请修订 <章节或场景> 的 <对白、叙事或触发范围>。以 <角色设定、剧情事实和玩法规则> 为准。用角色当时知道的事、眼前的目标和现场动作组织对白，保留各自的声线。
检查台词、动作与反馈的顺序。让玩家及时看懂行动所需的条件，同时保留 <留给玩家自己推断的内容>。
[可选] 用 $game-experience-review 评审 <关键决策片段>，核对对白是否让玩家掌握做决定所需的信息。
交付 <修订稿或实现改动>。有可运行版本时回看完整片段，核对语言、动作和信息时序。
```

体验评审流程见 [game-experience-review](../../skills/creative/game-experience-review/SKILL.md)。
